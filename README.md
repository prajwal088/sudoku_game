# Sudoku Game

## Project Description
Sudoku Game is a classic puzzle game that tests your logic and problem-solving skills. The goal of the game is to fill a 9x9 grid with digits so that each column, each row, and each of the nine 3x3 subgrids (also called boxes) contain all of the digits from 1 to 9.

## Features
- User-friendly interface
- Difficulty levels: Easy, Medium, Hard
- Hint system to assist players
- Save and load game state
- Responsive design for mobile and desktop

## Installation
To install the Sudoku Game locally, follow these steps:
1. Clone the repository:
   ```bash
   git clone https://github.com/prajwal088/sudoku_game.git
   ```
2. Navigate to the project directory:
   ```bash
   cd sudoku_game
   ```
3. Install the necessary dependencies:
   ```bash
   npm install
   ```

## Setup Instructions
- Ensure you have Node.js and npm installed on your machine.
- After installing the dependencies, you can start the development server:
  ```bash
  npm start
  ```
- Open your browser and go to `http://localhost:3000` to play the game.

## Usage Guide
- Select a difficulty level to start the game.
- Click on the grid to enter numbers.
- Use the hint feature if you're stuck.
- Complete the puzzle to win the game!
